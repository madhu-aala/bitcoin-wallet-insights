A lightweight web dashboard that allows users to analyze Bitcoin wallet activity, view transaction history, and track wallet balances using public blockchain data.

Features
- Wallet balance lookup
- Recent transactions
- Transaction fee display
- Wallet activity insights
- Simple dashboard UI

Tech Stack
- HTML
- CSS
- JavaScript
- Bitcoin API

How to Use
1. Enter a Bitcoin wallet address
2. Fetch wallet data
3. View analytics and transaction history
